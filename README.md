# Neural Network Foundations

A hands-on guide to understanding neural networks by implementing them
from raw NumPy, then comparing to PyTorch.

## Roadmap
1. Foundations — derivatives, the chain rule, a tiny autograd engine
2. MLP — the basic feedforward network + backprop
3. CNN — convolutions, pooling, image classification
4. RNN/LSTM — sequence modeling
5. Transformer — self-attention
